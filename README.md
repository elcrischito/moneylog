# MoneyLog — Personal Money and Expense Logging System

CPE 334 Group Project (KMUTT, semester 1/2026) · Team **EN-049** (`elcrischito`, solo) · Theme 7.

MoneyLog lets each person keep private records of their wallets, bank accounts, credit cards, loans, income and expenses, and see correct balances and income/expense summaries.

Engineering documents are in [`docs/`](docs/). Setup instructions are added with the Sprint 1 implementation.
